# Mobile Application (Hostel Mess Management System)

## Status
- **Planned Development**: React Native (Expo development builds, Android/iOS).
- **Backend API**: Consumes `/api/v1/` endpoints documented in `docs/openapi/schema.yaml`.
- **Target Roles**:
  - **Student**: Dynamic rotating QR display (offline TOTP generation via local 32-byte secret).
  - **Mess Manager**: Offline scanning and transaction recording with batch sync protocol.
